How the magnet works 🧲

    
Sensor: checking…

    
    
      
  1. Tap Start, keep the phone still for 2 s with the magnet away.
    2. 
      
  2. Bring a magnet close to the top half / back of the phone (that's where the compass chip usually is). Strong fridge or speaker magnets work best.
    3. 
      
  3. Things fly the wrong way? Tap ⇄ Flip. Want them to always go to one side? Pick a side below.
    4. 
      
  4. Moved the phone a lot? Tap Recalibrate.
    5. 
      
  5. Not moving? Tap 📊 (top) to see live sensor values: which path is active, heading, and how much the magnet bends it.

      Phone not reacting? (Android Chrome extra-accurate mode)
      
Most Android phones work out of the box (we read the compass). For the most accurate, direction-aware magnet on Android Chrome:

      
    
        
  1. Open a new tab and type chrome://flags
    2. 
        
  2. Search Generic Sensor Extra Classes → set Enabled
    3. 
        
  3. Tap Relaunch, then open this page again
    4. 
      

      
iPhone: Safari asks for "Motion & Orientation" when you tap Start, allow it. If you said no, close the tab and open the page again.

      
No compass at all (laptops, some tablets)? Hold or drag on the screen to act as the magnet.
